사용법

· 단가 자동 — 날짜와 골프장을 고르면 날짜로 시즌(High/Low)과 평일/주말을 판단해 단가표의 Total을 넣습니다. 태국 공휴일(단가표 탭에서 관리)은 자동으로 공휴일(주말요금)이 됩니다. 특별한 경우 시즌·요금 칸을 직접 바꾸면 됩니다.
· 단가 직접 수정 — 단가 칸에 숫자를 직접 쓰면 직접 표시가 붙고 자동계산을 덮어씁니다. 되돌리려면 칸을 비우세요.
· 27홀·36홀 — 27H는 그 날짜의 18H+9H 단가, 36H는 18H×2 단가가 자동으로 들어갑니다. 9H 단가가 없는 골프장은 27H 단가를 직접 입력하세요.
· 골프장 목록에 없는 코스 — 골프장 선택에서 직접입력을 고르고 이름·단가를 쓰면 됩니다.
· 데이터 보관 — 이 컴퓨터의 브라우저에 저장됩니다. 다른 PC로 옮기려면 저장 목록 → 전체 백업을 이용하세요.
· 파일을 USB에 복사해 다른 PC에서 더블클릭해도 그대로 동작합니다(저장 내용은 백업파일로 옮기세요).
